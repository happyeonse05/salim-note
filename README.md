# 오늘 살림

장바구니와 생활 기록을 관리하고 빨래 남은 시간, 복용 체크, 지출을 함께 확인하는 자취살림 앱입니다.

[오늘 살림 열기](https://happyeonse05.github.io/salim-note/)

- **오늘**: 진행 중인 빨래·아직 기록하지 않은 복용 일정을 먼저 보여주고, 완료 기록은 아래에 모읍니다. 사용하지 않은 기능은 빈 카드로 표시하지 않습니다.
- **기록 추가**: 최근·자주 쓴 빨래와 약을 먼저 표시합니다. 빨래는 한 번 눌러 시작하고, 지출은 금액만 바로 저장합니다. 종류를 고르면 해당 입력만 보여줍니다. 약·화장품 등록도 이 화면에서 합니다.
- **장바구니·살림 관리**: 하단 장바구니와 오늘 화면의 살림 관리 메뉴에서 살 물건·장보기 기록, 옷 구매, 식품·화장품 사용기한, 날짜별 빨래 기록과 사진, 반복 집안일·캘린더 내보내기를 사용합니다. 기록 수정·삭제·검색·정렬, 사진 첨부·확대, 백업 가져오기를 지원합니다. 복용 관리에서는 복용량·요일·시작일·종료일을 직접 입력할 수 있습니다. 상단 ‘오늘·타이머·지출’로 돌아옵니다.
- **지난 기록**: 날짜별 기록, 지출 수정, 약 일정·항목별 알림, 선택형 주간 예산과 백업을 관리합니다.

## 기록과 알림

계정 없이 이 브라우저의 로컬 저장소에 저장합니다. 다른 기기와 자동 동기화되지 않으며 브라우저 데이터를 지우면 기록을 잃을 수 있으므로 지난 기록에서 백업할 수 있습니다.

널지 않은 빨래는 다음 날에도 ‘어제부터 · 빨래 널기’로 이어집니다. 약의 어제 체크를 오늘 할 일로 이월하지 않으며, 홈에서는 마지막 실제 체크 시각을 보여줍니다. 지출은 입력한 실제 날짜를 유지합니다.

빨래는 시작 시각과 종료 시각을 저장하므로 앱을 다시 열어도 남은 시간을 계산합니다. 세탁기와 연결된 기능이 아니며 시간이 지나면 ‘설정 시간 끝’으로 표시합니다.

복용 체크는 사용자가 누른 시각만 남깁니다. 체크가 없다는 이유로 복용하지 않았다고 판단하지 않습니다. 잘못 누른 기록은 바로 취소할 수 있습니다. 복용법은 처방과 제품 설명을 따릅니다.

웹 알림은 항목별로 직접 켭니다. 앱이 열려 있을 때만 동작하며, 앱을 닫은 동안의 알림 전달은 보장하지 않습니다. 복용 알림 제목과 본문에는 약 이름을 넣지 않습니다.

주간 지출은 기기 현지 시간의 월요일부터 일요일까지 합산합니다. 예산은 직접 설정한 경우에만 표시합니다.

## 기존 앱 데이터 보존

기존 `salimnote-*` 저장 키와 형식은 변경하지 않습니다. 처음 열 때 기존 복용 일정·체크를 읽어 이어서 보여주고, 새 기록은 별도 `oneul-salim-v1` 키에 저장합니다. 기존에 금액을 기록한 옷 구매 항목은 날짜만 있는 지출로 이어서 표시합니다. 원래 금액·날짜와 저장 데이터는 그대로 보관됩니다.

기존 빨래·장보기·식품·화장품·반복 일정·살 물건·첨부 사진은 복구된 살림 관리 화면에서 계속 조회·추가·수정할 수 있으며 지난 기록의 원본 보기와 백업에도 남습니다. 약·화장품은 오늘 화면과 살림 관리가 같은 현재 저장 데이터를 사용하고, 기존 원본 사본은 보존합니다. 두 화면을 동시에 열어 다른 쪽에서 변경했다면 새로고침 후 저장해야 합니다. 식품·화장품 사용기한을 새 기준으로 계산하거나 변경하지 않습니다.

## 로컬 확인

정적 파일 앱으로 추가 의존성이나 빌드가 필요하지 않습니다.

```sh
python3 -m http.server 8901 --bind 127.0.0.1
node --test tests/core.test.cjs
```

테스트는 타이머 복원, 복용 체크 취소, 지출 수정 및 주간 경계, 기존 복용 일정·기록 호환성을 확인합니다. 사용자 기록은 테스트 코드나 저장소에 포함하지 않습니다.

## 약의 식사 조건과 화장품 기한

`care-core.js`에 확인일·공식 출처와 함께 타이레놀정 500mg, 타이레놀8시간이알서방정 650mg, 개비스콘 더블액션 현탁액의 일반 제품 안내를 제공합니다. 함량과 제형을 직접 선택해야 적용되며 별칭만으로 제품을 추정하지 않습니다. 다른 제품은 약 봉투·약사에게 확인한 공복 시간과 메모를 직접 남깁니다. 개인별 복용 가능 여부나 다음 복용 가능 시각을 자동 판정하지 않습니다. 필요시 복용하는 약은 정기 시간 표시를 끌 수 있습니다.

화장품은 종류·개봉일·제품 표시 개봉 후 사용기간(PAO)·포장 사용기한을 등록합니다. 종류만으로 사용기한을 추정하지 않습니다. 개봉일에 표시 개월 수를 더한 날짜와 포장 날짜 중 이른 날짜를 관리 날짜로 표시합니다. 월말은 해당 월의 마지막 날짜로 맞춥니다. 날짜는 사용 안전성 판정이 아니며 기한 미확인 상태도 저장할 수 있습니다. 사용 완료·다시 사용과 수정이 가능합니다. 30일 이내 날짜 또는 기한 미확인 항목만 홈에 표시합니다.

기존 화장품 등록값은 원본을 보존한 사본으로 이어서 보여줍니다. 새 화장품과 약 상세는 기존 새 앱 저장소 `oneul-salim-v1`의 추가 필드에 저장되며 전체 백업에 포함됩니다.

추가 기능 확인: `node --test tests/*.test.cjs` (이월·마지막 기록·주간 날짜 경계·월말/윤년 기한·빠른 시작 순위 포함).

## 기능 보존 원칙과 점검 목록

기존 기능을 빼지 않고 추가·개선합니다. 화면 단순화·디자인 개편을 이유로 메뉴나 기능을 없애거나 읽기 전용 과거 기록으로 대체하지 않습니다. 삭제·대체로 기능이나 접근 경로를 없애는 작업은 사용자가 별도로 명시적으로 요청한 경우에만 합니다. 매 변경 전후 아래 목록을 비교합니다.

- 장바구니 품목 담기·체크·제거, 체크한 품목의 구매 기록 전환
- 빨래 날짜·메모, 장보기 내역, 옷 구매 날짜·가격, 식품 표시기한·보관 메모
- 생활 기록 추가·수정·삭제·검색·정렬, 사진 첨부·제거·확대
- 화장품 제품 표시 PAO·개봉일·포장 기한, 사용 완료·되돌리기와 기존 사진·메모
- 복용량·시간·요일·시작/종료일, 실제 복용 체크·취소, 필요시 기록, 제품·식사 안내와 선택형 알림
- 반복 집안일 등록·수정·완료·삭제, 다음 날짜 계산, .ics 캘린더 내보내기
- 빨래 타이머 재개·널기·취소·어제 이월, 빠른 기록, 날짜별 지출·수정·주간 집계·선택형 예산
- 기존·현재 저장 데이터 보존, 전체 백업, 두 세대 백업 가져오기(같은 ID는 현재 기록 우선)

복구 화면은 `household.html`, 스타일은 `household.css`, 동작은 `household.js`에 있습니다. `household-bridge.js`가 두 화면의 약·화장품·구매 지출을 연결하고 잘못된 저장값·동시 변경·저장 실패로 원본을 덮어쓰지 않게 합니다. 사용기한은 제품에 표시된 날짜·기간만 사용하며 종류별 기간을 새로 추정하지 않습니다.
